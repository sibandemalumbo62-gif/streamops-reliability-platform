# StreamOps Reliability Platform

A cloud-native Site Reliability Engineering platform that simulates the infrastructure behind a large-scale streaming service.

## Goals

- High Availability
- Reliability Engineering
- Observability
- Automation
- Incident Response
- Distributed Systems
- Cloud-Native Architecture

- Prometheus
- Grafana
- Loki
- OpenTelemetry
- Jaeger
- GitHub Actions
